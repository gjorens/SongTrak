Many songs at once (Auto-add from My tabs)

  1. On Ultimate Guitar open My tabs, choose Chords, and scroll down so the rows you want are loaded.
  2. Click Auto-add from My tabs. Enter the row to start at (1 is the first row), then how many (try 25, or type all for every row loaded on the page).
  3. Safari may open the first song's page. If it does, click Auto-add from My tabs again when it has loaded. A green box counts through the songs, about 2 to 3 seconds each (25 songs take about a minute). Stop ends early.
  4. The box ends with a Copy button for the whole batch and the row to start at next time. The Copy button empties the batch once it has copied, so the next run starts fresh. Import with Import > From clipboard (or paste into a plain text file) and import as in steps 4 and 5 below. Repeat for the next batch.

One song at a time

  1. Open a chord page on Ultimate Guitar (logged in) and click Add to SongTrak batch. A green note shows the song title and how many are in the batch. Clicking it again on the same page just updates that song.
  2. Go to the next song and repeat. The batch is kept in Safari, so you can stop and come back.
  3. When you are done, click Copy SongTrak batch on any Ultimate Guitar page. It copies every song and asks whether to clear the batch.
  4. Open TextEdit, choose Format > Make Plain Text, paste, and save as ug-songs.txt.
  5. In SongTrak tap the Import button and choose that file (or drag it onto SongTrak). It finds every song, and the section names, chords, N.C. and bracketed comments are converted.
